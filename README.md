# 웹소설 분석 대시보드

이 프로젝트는 웹소설 시장의 트렌드와 성과를 분석하여 대중의 니즈를 파악하고, 정형화된 웹소설 IP 소싱을 벗어나 유니크한 방향성을 탐색하기 위한 웹 애플리케이션입니다.

## 주요 기능

1. 장르별 키워드 분석
2. 선택한 키워드 조합에 따른 작품 분석
3. 장르별 TOP 10 작품 분석
4. 키워드 중요도 및 순위 시각화
5. 작품별 예상 수익 및 인기도 분석

## 기술 스택

- Backend: Flask (Python)
- Frontend: HTML, CSS, JavaScript
- 데이터베이스: SQLAlchemy
- 차트 라이브러리: Chart.js
- 데이터 처리: pandas, numpy

## 설치 방법

1. 저장소를 클론합니다:
   ```
   git clone [저장소 URL]
   ```

2. 필요한 패키지를 설치합니다:
   ```
   pip install -r requirements.txt
   ```

3. 데이터베이스를 설정합니다:
   ```
   flask db upgrade
   ```

4. 애플리케이션을 실행합니다:
   ```
   python app.py
   ```

## 사용 방법

1. 웹 브라우저에서 `http://localhost:5001`에 접속합니다.
2. 원하는 장르와 키워드를 선택합니다.
3. 분석 결과를 확인합니다.
